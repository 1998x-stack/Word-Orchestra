# Word Orchestra

**Every word becomes music.**

Word Orchestra combines English vocabulary practice, keyboard input, and generative music. Each keystroke produces a stable note, each completed word becomes a musical motif, and phrases form musical sentences—while language mastery, typing skill, and musical output are measured independently.

> Word Orchestra is the learning-led product. It is not a free-typing piano or a rhythm/reaction game. Free-form keyboard-to-music exploration belongs to [Piano Typing](https://github.com/1998x-stack/Piano-Typing).

## Product principles

- Music motivates practice; it does not substitute for learning.
- Copying is practice, not proof of mastery.
- Measure delayed recall, meaning, spelling, listening, and contextual use separately.
- Adapt language and typing difficulty independently.
- Avoid punitive streaks, loss aversion, and manipulative reward loops.
- Keep practice local by default and never capture system-wide keyboard input.

## Planned technology baseline

- React + TypeScript + Vite
- Web Audio API for deterministic low-latency sound
- IndexedDB for local learning history and compositions
- Vitest + Testing Library for domain and component tests
- ESLint + TypeScript + production build checks in CI

No backend, account, LLM provider, or remote keyboard telemetry is required for the MVP.

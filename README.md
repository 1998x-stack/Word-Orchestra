# Word Orchestra

**Every word becomes music.**

Word Orchestra combines English vocabulary practice, keyboard input, and generative music. Each keystroke produces a stable note, each completed word becomes a musical motif, and phrases form musical sentences—while language mastery, typing skill, and musical output are measured independently.

> Word Orchestra is the learning-led product. It is not a free-typing piano or a rhythm/reaction game. Free-form keyboard-to-music exploration belongs to [Piano Typing](https://github.com/1998x-stack/Piano-Typing).

## Product principles

- Music motivates practice; it does not substitute for learning.
- Copying is practice, not proof of mastery.
- Measure delayed recall, meaning, spelling, listening, and contextual use separately.
- Adapt language and typing difficulty independently.
- Avoid punitive streaks, loss aversion, and manipulative reward loops.
- Keep practice local by default and never capture system-wide keyboard input.

## Current implementation

Phase 0 foundation and the first playable slice are implemented on the engineering branch.

Implemented:
- React + TypeScript + Vite application shell.
- Copy and Recall practice modes with a small bilingual starter vocabulary set.
- Stable C-major pentatonic letter-to-note mapping.
- Web Audio API synthesizer with lazy unlock, mute, gain envelope, and overlapping-voice cap.
- Session composition event capture and replay.
- IndexedDB session history and a separate progress view.
- Domain rules and tests that keep Copy separate from recall evidence.
- CI checks for lint, typecheck, tests, and production build.

This is an interaction prototype, not yet the full learning product. Listen, Context, FSRS scheduling, content import, export/import, and validated delayed-recall reporting remain later phases.

## Quick start

Requirements: Node.js 20.19+ (Node 22 recommended).

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run test -- --run
npm run build
```

No backend, account, LLM provider, or remote keyboard telemetry is required.
